 ******** Project Description ********
     * 
     * This project is a just-for-fun interactive aquarium simulator.
     * The problem this project tries to address is being able to have pet fish without the stakes of having real pet fish.
     * The program opens up a new aquarium object. This includes a graphical representation of a tank with swimming fish
     * as well as an interactive area at the top. The tank is continually animated to have the fish move.
     * 
     * The main purpose of this project is to provide a fun desktop visual experience. The tank starts off with one
     * default red fish. It has the option at the top of the window to add more fish. The user can even select
     * if they want their next fish to be red, yellow, or purple. The fish swim around in random directions but are bound
     * to the confines of the tank water. The amount of fish in the tank is counted, since after several clicks of "Add Fish!" it
     * becomes increasingly hard to keep count of the pet fish as they are swimming around.
     * 
     * As a fun feature, the user can simulate turning off the tank light and enter "Night Mode" by right clicking.
     * The fish are then in party mode now, so they have glow-in-the-dark hues of green and swim faster.
     * Right clicking once more returns to regular day operations.

    * Run main.java to create an instance of Aquarium
    * Aquarium.java contains the class Aquarium with all the objects needed
